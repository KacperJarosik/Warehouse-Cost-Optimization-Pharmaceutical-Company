# Warehouse Cost Optimization — Pharmaceutical Company

## Overview

This project addresses **demand forecasting** and **inventory optimization** for a pharmaceutical company managing 250 products. Using historical sales data (2023–2025), we train time-series models to predict future demand and compute optimal inventory levels that minimize storage costs while avoiding stockouts.

## Business Objective

- Reduce warehouse holding costs through data-driven inventory planning
- Minimize lost revenue from stockouts by maintaining appropriate safety stock
- Outperform static financial plan forecasts with adaptive statistical models
- Generate actionable 2026 sales and inventory predictions

## Methodology

### 1. Exploratory Data Analysis
- Distribution and seasonality analysis of sales across all products
- Inventory level patterns and stockout frequency detection
- Correlation between product parameters and demand volatility

### 2. Forecasting Model — Holt-Winters (Triple Exponential Smoothing)
- **Training data:** 24 months (2023–2024)
- **Validation:** 12 months (2025 actuals)
- **Forecast horizon:** 12 months (2026)
- Handles additive trend and 12-month seasonal cycle
- Fallback to seasonal naïve for products where optimization fails

### 3. Inventory Optimization
- Optimal stock = forecast demand + safety stock buffer (product-specific)
- Safety stock derived from `Safety_stock_months` × mean future demand
- Comparison against actual inventory levels and financial plan estimates

### 4. Financial Impact Analysis
- Storage cost savings: model-optimal vs. actual inventory
- Additional revenue from avoided stockouts (20% profit margin assumption)
- Bootstrap confidence intervals for all financial estimates
- Per-product and aggregate benefit quantification

## Data Description

| File | Records | Description |
|------|---------|-------------|
| `sales_train_2023_2024.csv` | 500 rows (250 products × 2 types) | Monthly sales and inventory for training |
| `sales_test_2025.csv` | 500 rows | Monthly sales and inventory for evaluation |
| `products_parameters.csv` | 250 rows | Storage cost, shelf life, lead time, safety stock, price |
| `financial_plan.csv` | 250 rows | Annual unit and revenue plans per product |

**Key columns in product parameters:**
- `Storage_cost_PLN_per_unit_month` — monthly holding cost per unit (PLN)
- `Shelf_life_months` — product expiry window
- `Lead_time_months` — supplier delivery time
- `Safety_stock_months` — recommended buffer in months of demand
- `Price_PLN_per_unit` — unit selling price

## Usage

1. Clone or download this repository
2. Install dependencies (see above)
3. Open notebooks in Jupyter or VS Code:
   - Start with **EDA CSV files.ipynb** for data exploration
   - Run **model_and_optimization.ipynb** for full forecasting pipeline
4. Output files (`predictions_2026.csv`, `optimization_results_2025.csv`) are generated in the working directory

## Output Files (generated by model notebook)

| File | Content |
|------|---------|
| `predictions_2026.csv` | Monthly sales forecast and optimal inventory for all 250 products (2026) |
| `optimization_results_2025.csv` | Per-product cost comparison: actual vs. model-optimal (2025) |
| `model_vs_plan_comparison.csv` | Model accuracy vs. financial plan benchmark |
